## Overview

MIDI Guitar 3 converts live guitar audio to MIDI in real time with polyphonic pitch detection, ultra-low latency, and configurable sensitivity for triggering any virtual instrument from a guitar.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Jam Origin MIDI Guitar** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Polyphonic Detection** | Detect up to 6 simultaneous pitches from guitar audio input |
| **Ultra-Low Latency** | Under 5ms detection latency for responsive real-time performance |
| **Pitch Bend** | Per-string pitch bend MIDI output matching guitar vibrato and bends |
| **MIDI Routing** | Route detected MIDI to any DAW instrument or external MIDI device |
